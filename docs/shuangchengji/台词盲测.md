# 双城记 · 台词定稿盲测

> 目的：找出哪个 AI 写的台词最符合 Hestia 的感觉，之后由它做「编剧最后一稿」。
> 用法：把下面「给 AI 的任务」整段原样发给每个 AI（Claude、KIMI、Codex……），每个都用新对话，不要给它看别人的答案。把回答收齐后交给 Hestia 以外的人（或另一个 AI）打乱顺序、去掉署名，标成 A / B / C，Hestia 再按评分表打分。

---

## 给 AI 的任务（整段复制）

你在帮一款手机剧情游戏《双城记》做台词的最后一稿。游戏是作者 Hestia 的日记：人物都是她的真实朋友，情节是真事。请把下面两场的台词改成定稿。

**规则**
1. 标 【原话】 的句子是 Hestia 的原话，**一个字都不能改**，只能决定它前后接什么。
2. 不能加新的情节、新的设定、新的人物背景。只能改写、删减、调整顺序，或补很短的过渡句。
3. 旁白用「我」的视角，短句，克制，不煽情。
4. 每句台词不超过 20 个字，适合手机对话框。
5. 输出格式照原稿：`角色：台词`，一行一句；最后用三句话说明你改了什么、为什么。

**人物**
- 我：玩家本人，工作室主人，说话随意、有点皮。没有形象，保持神秘。
- D：00 后女生，内向、敏感、有才华，不爱张扬，做事认真，总觉得作品还能更好一点；神经大条，常把东西落在工作室。说话短，常用省略号。
- J：极客，技术达人，重度装备党，很热情，几乎什么都能修，说话爱比手势。和 D 第一次见面，两个人都不好意思。

**第一场：瑞士卷（D 早上来工作室，带了一盒瑞士卷）**

```
旁白：D 来了，比约好的还早。手里提着一盒瑞士卷。
D：……顺路买的。
旁白：我们看着那一整条瑞士卷，谁都不知道该怎么分。
我：等一下。
（我用 3D 打印机打印了一把刀，用它切开了瑞士卷）
D：这也可以吗？【原话】
我：这怎么了，我还打印过夹子，就为了方便自己吃薯片不沾手。【原话】
旁白：D 大概想到了那个画面，低头笑了半天。
```

**第二场：书签打成功了（之前打失败了好几次，J 帮忙找到原因，这次成功了）**

```
旁白：透明的底，白色的线。对着窗户举起来，像一小块欧根纱。
（D 接过书签）
D：……跟我画的时候想的一样。
旁白：她把书签翻过来，又翻回去，手指沿着边摸了一圈。
D：边上也是平的。
D：谢谢你们。
旁白：说完她就把书签收进了包里，很小心，像怕被谁看见她有多高兴。
J：（他会怎么接？请补一到两句）
```
