# 双城记 · 数据待补与技术核对

> 给协作的 AI（KIMI / Codex 等）看的工作单。由 Claude 维护，2026-10-19 建立。
> 游戏：`public/shuangchengji/index.html`（H5 合成剧情游戏，作者 Hestia，基于她的真实 3D 打印经历）。
> 打印机：**拓竹 Bambu Lab A1，0.4 mm 喷嘴，0.2 mm 层高**，切片软件 Bambu Studio。

## 怎么协作

1. **只在 `shuangchengji-data` 分支上改这个文件**，不要改 `main`（推送 `main` 会自动发布网站），也不要改游戏代码。
2. 填完一项：把这一项的「状态」从 `待填` 改成 `已填`，在「来源」里写清楚依据（切片截图路径、链接、文档页）。截图放在 `docs/shuangchengji/截图/` 下。
3. 提交信息用：`数据待补: <项目名> 已填`。
4. 推送后告诉 Hestia，Hestia 会转告 Claude；Claude 拉取这个分支，把数据写进游戏，再把这一项的状态改成 `已入游戏`。
5. 不确定的地方写在「备注」里，不要猜数字。游戏的规则是：层数、时间、克重必须和真实切片一致。

## 一、切片数据

### 每件物品要交什么

| 要交的 | 必须？ | 格式和放哪里 | 用来做什么 |
|---|---|---|---|
| MakerWorld 模型页链接、模型名、作者 | 必须 | 写在下面 JSON 里 | 游戏内署名（仓库里有 ATTRIBUTIONS.md） |
| 许可证 | 必须 | JSON 里，照模型页写（如 CC BY 4.0、Standard Digital File License） | 判断能不能在游戏里展示、署名怎么写 |
| 切片数据（见下方字段） | 必须 | JSON 里 | 游戏里的层数、打印时间、克重必须和真实切片一致 |
| 切片截图 | 必须 | PNG 或 JPG，`docs/shuangchengji/截图/<id>_切片.png` | 核对数据；截图和 3mf 估算不一致时**以截图为准** |
| 模型预览图 | 必须 | PNG 或 JPG，至少 800 px 宽，`docs/shuangchengji/截图/<id>_预览.png`；有侧视图最好 | Claude 照着画游戏里的手绘图标 |
| 外形尺寸 长×宽×高（mm） | 必须 | JSON 里，从切片软件或模型页读 | 桌上按真实比例摆放（1 mm ≈ 0.4 单位） |
| 模型文件 3MF / STL | **不需要** | 不要传 | 现在是 2D 手绘图标，用不上；以后换引擎再说 |

切片条件统一：**拓竹 A1，0.4 mm 喷嘴，0.2 mm 层高，Bambu Studio 默认参数**，耗材用模型页推荐的或白色 PLA（Hestia 偏好白色）。如果模型页自带的切片配置不是 A1（比如是 A1 mini 或 X1），请换成 A1 重新切片再截图，并在备注里说明。

## 二、技术核对（请懂 3D 打印的 AI 验证，并给补充）

> 下面是剧本里写进去的技术说法。请逐条判断「对 / 不对 / 不完整」，给出依据（优先拓竹官方 wiki 或 Bambu Studio 文档），并补充剧本可以用的细节。

### 2.1 看小船（3DBenchy）找问题

剧情：一卷便宜耗材打双层书签，表面凹凸不平（有拉丝）。用刚开封的新耗材打小船测试，最后判断是「熔点过低」：这卷耗材需要的温度比默认低，按默认温度打就过热；热床温度也偏高。

| 小船的样子 | 问题 | 目前依据 | 核对结论 |
|---|---|---|---|
| 船身软塌、层像化了，船头悬空部分下垂 | 温度太高（耗材熔点比设定低） | 拓竹 wiki「过热/下垂」：散热不够、速度太快、温度太高，PLA 默认 220 °C | 待填 |
| 表面一个个小疙瘩 | 耗材受潮 | 拓竹 wiki「表面随机小点」：受潮，新开封也建议烘干 | 待填 |
| 顶面线条之间均匀的缝 | 挤出不足 | 拓竹 wiki「挤出不足」：流量比例低、齿轮脏、喷嘴半堵 | 待填 |
| 船身中间一截错开 | 层偏移 | 拓竹 wiki「层偏移」 | 待填 |
| 船底翘起 | 翘边 | 拓竹 wiki「翘边」：板子类型或热床温度不对 | 待填 |

依据页面：https://wiki.bambulab.com/en/knowledge-sharing/troubleshooting-printing-issues-backup

需要回答：
1. 「熔点过低 + 热床温度高」时，小船和薄片书签实际会是什么样子？「拉丝」和「表面凹凸不平」是否都说得通？
2. 改参数时，喷嘴温度和热床温度大概调到多少比较合理（A1，纹理 PEI 板，PLA）？给一个范围即可，Hestia 会定最终数字。
3. 拉丝更常见的原因是受潮还是温度高？剧情里 J 说「现在就下定论说是烘干的问题，有点为时过早，最快的方法是拿一卷刚开封的新耗材打小船」，这个排查顺序是否合理？

### 2.2 耗材烘干的几种方式

剧本里 J 讲：有人自制烘干机；有人用烘被子的设备；有人放进洗衣机里烘干；这些都有风险，可能导致耗材变形；也有厂商做了专门的烘干设备，精准控制温度，但比较贵。

需要回答：说法是否准确；PLA 常见的烘干温度和时间；还有什么值得一提的风险。

### 2.3 砂纸打磨

剧本：简单的毛边用低目数砂纸；复杂的从低到高目数打磨。游戏里暂定四档：240 → 400 → 800 → 1500（最后一档湿磨）。

需要回答：这四档对 PLA 打印件是否合适；有没有更常见的组合。
