# 双城记 · 人物立绘工作单（给 Codex 出图）

> 由 Claude 维护，2026-10-19 建立。游戏是 Hestia 以真实生活为蓝本做的手机剧情 + 合成游戏。人物都是她的真实朋友，外形特征只用下面写的，不要自己加设定。
> 画风问题的完整讨论在项目文件「美术与iOS路线_讨论.md」，Hestia 的决定以她最新的话为准。

## 怎么协作

1. 只在 `shuangchengji-data` 分支上提交，放在 `docs/shuangchengji/立绘/` 下。**不要推 `main`**（会自动发布网站），不要改游戏代码。
2. 文件名：`<角色>_<类型>_<名字>.png`，例如 `J_全身_拿相机.png`、`J_表情_认真.png`、`N_头像_冷脸.png`。
3. 推送后告诉 Hestia。Hestia 挑定以后告诉 Claude，Claude 负责压缩、裁头像、接进剧情。

## 画风基准

- 参考图：`docs/shuangchengji/参考/D_全身.png`、`docs/shuangchengji/参考/D_头像.png`（D 现在游戏里用的 Q 版）。新角色要和 D 站在一起像同一个游戏。
- Q 版手游立绘，**2.5 头身**，大头小身，正面站姿。
- 粗而均匀的暖棕色描边（接近 #6E4A31），平涂上色加一层柔和阴影，头发分成简洁的大块、少碎发。
- 奶油色和莫兰迪色调（青绿、鼠尾草绿、少量陶土色）。
- 表情包贴纸风格，**透明背景**。
- 提示词统一结尾：`粗而均匀的暖棕色描边，平涂上色加一层柔和阴影，奶油色和莫兰迪色调，表情包贴纸风格，透明背景`
- 画面里不要出现真实品牌 logo。

## 规格

| 项目 | 要求 |
|---|---|
| 格式 | PNG，透明背景 |
| 全身尺寸 | 宽至少 1170 px，人物占满画面高度，脚底贴近画布下边 |
| 一致性 | 所有角色同样的头身比、同样的脚底线、视线高度接近；同一角色换表情时，身体、头发、衣服、位置都不动 |
| 表情差分 | **先出一张满意的定稿全身，再用「参考图 + 只重绘脸部」出表情**，不要每张从头生成，否则脸会跑 |
| 头像 | 不用单独画，Claude 从表情图里裁 |

## 按优先级

### 1. J（第三天第一次出场，最急）

真实特征（Hestia 提供）：男生，戴眼镜，黑色短发，灰紫色 T 恤，戴运动手表，说话爱比手势。极客、技术达人、重度装备党，很热情，几乎什么都能修。

| 要出的图 | 说明 |
|---|---|
| 全身 · 拿相机 | 一只手拿着一台小型手持云台相机（现实里是大疆 Pocket 4P，画面里不要 logo），热情地笑。用于出场和新人物卡片 |
| 自拍照 | 他一个人的自拍：手臂伸向镜头，另一只手比手势，背景是工作室门口。剧情里他想搂着「我」自拍，「我」躲开了，照片里只有他自己。这张做他的联系人海报，**不是透明背景**，竖图 9:16 |
| 表情 · 热情笑 | 定稿表情 |
| 表情 · 认真讲解 | 一边讲一边比手势（讲耗材烘干和测试小船时用） |
| 表情 · 吐槽 | 「是不是你买了什么杂牌的耗材？」那种嫌弃又好笑的表情 |
| 表情 · 惊讶 | 「你这里还能吃饭？」 |

### 2. N（第三天结尾只出现头像，第四天出场）

真实特征（Hestia 提供）：女生，冷面，中发（到脖子）、自然卷，与世无争的冷脸。怪咖天才，说话冷淡，口头禅「怎么说呢」。来自热带，所以总穿很多衣服，戴很厚的帽子和手套。

| 要出的图 | 说明 |
|---|---|
| 头像 · 冷脸 | **第三天就要用**：手机聊天里的头像，方形，冷脸。可以先出这一张 |
| 全身 · 裹得很厚 | 第四天用：穿很多层衣服、厚帽子、手套，冷脸 |
| 表情 · 鞠躬 | 聊天里的「鞠躬」表情，可以做成小贴纸，参考 D 的恐龙表情包大小 |

真实特征：00 后女生，粉色头发，内向、敏感、有才华；戴一个**粉色小恐龙发卡**（Hestia 10-18 确认，现有图里还没有）。

| 要出的图 | 说明 |

| 新定稿全身 | 以现有 D 为参考，加上粉色小恐龙发卡，线条改得更粗、更 Q，和上面的画风基准一致 |
